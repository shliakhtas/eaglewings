# Що нового з'ясовано

Лише те, що є в [LIMITATIONS](LIMITATIONS.md); числа — тест переможця з 95 % CI. Джерела методів — у [SOURCES](SOURCES.md). Новизна тут — це новий результат на цій території, перевірка перенесення між територіями, чесно поміряний негативний результат або нова перевірка самого інструменту. Методи самі по собі не нові.
