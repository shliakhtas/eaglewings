# Ліси Фракії: що відкриті супутникові дані кажуть про три національні парки Греції

Дослідження трьох національних парків Фракії — Дадья–Лефкімі–Суфлі, «Дельта Евросу», «Східна Македонія й Фракія» — на відкритих даних за 2021–2025 роки. Головний випадок — пожежа в Евросі в серпні 2023 року. Для кожного з 16 питань змагались кілька алгоритмів; переможця обирала лише валідація, тест показує результат із 95 % інтервалом, окремо для кожного парку.

Що вийшло, коротко: згарище 2023 картографується з Sentinel-2 з F1 0,87 (0,81–0,91); теплові точки двох супутників правильно зводяться в пожежі з урахуванням часу (BCubed F1 0,99 проти 0,64); пожежі повертаються на ті самі місця, але гарні контури не кращі за просте «де вже горіло». Прогнози дня пожежі, ризику й рубок слабкі — і це теж у звіті. Повно: [docs/LIMITATIONS.md](docs/LIMITATIONS.md).

Це базовий приклад бібліотеки **EagleWings**: проєкт створено скілом `new-study` ([протокол](docs/CREATION.md)), а код живе в бібліотеці.

## Запустити

Потрібно: Python 3.11, бібліотека EagleWings, для детекторів — GPU з CUDA 12.8. Ключі для даних не потрібні: усі набори відкриті. ClearML необов'язковий (`~/clearml.conf`); без нього потік пише локально в `logs/runs/`. Ключ OpenAI чи Anthropic для чату вводиться в застосунку й живе лише у вкладці браузера та в самому запиті. Встановлення — у README бібліотеки.

```bash
cd demo/greece                               # тека цього проєкту

eaglewings plan                              # кроки й задачі простими словами, нічого не запускаючи
eaglewings run                               # повний прогін (години): дані → датасети → гілки → моделі → сайт → документи
eaglewings run --clearml                     # те саме з записом у ClearML
eaglewings run FG_risk LD                    # лише ці гілки
eaglewings run --from LD                     # гілка змінилась: вона й усе, що після неї
eaglewings serve                             # сайт, порт 8766 (або ./run.sh)
eaglewings assistant                         # агент чату, порт 8770 (або ./run_assistant.sh), потрібен ключ OpenAI чи Anthropic
```

Prefect має працювати: `prefect server start --host 127.0.0.1 --port 4200`. Без прогону кейс можна подивитися на https://eaglewings.noosvit.com: дані й зібрані сторінки (близько 220 МБ) у репозиторій бібліотеки не входять, `eaglewings run` завантажує відкриті дані й збирає все заново.

## Будова теки

| Шлях | Що там |

| `models/` | переможець кожної гілки: `card.json` і модель |

## Обмеження

Потік сигналів у застосунку сценарний, на реальних місцях парку; реальні лише 12 детекцій диму з камери в Дадьї. Згарище стверджуємо лише для Дадьї. Ризик ділянок працює в Дельті й Східній Македонії, але не в Дадьї. Рубок мало, інтервали широкі. Деталі — [docs/LIMITATIONS.md](docs/LIMITATIONS.md).
