# Артефакти

Сторінки, які пояснюють проєкт, і звіти, які пише потік.

| Файл | Що це |
|---|---|
| `architecture.html` | архітектура: кроки потоку, що відбувається всередині задачі, куди йдуть результати, як запускати |
| `branches.html` | карта гілок: вхід, алгоритми, метрики, обраний варіант |
| `reports/` | сторінки-звіти, які пише `flows/pipeline.py` (`ds/pages.py`): `source-*` скачані набори, `dataset-*` датасети, `task-*` задачі, `summary` зведення. Ті самі сторінки є в Prefect (вкладка Artifacts) і, з `--clearml`, у ClearML |

Звіти генеруються, тому в репозиторії їх немає: вони з'являються після запуску потоку. Рішення й підходи: [docs/DECISIONS.md](../docs/DECISIONS.md).
